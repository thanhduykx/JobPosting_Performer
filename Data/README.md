# 📂 Data Folder - Cấu trúc dữ liệu

## 📁 Tổ chức thư mục

### 🎨 **UI/** - Giao diện HTML
Chứa tất cả các file HTML dashboard và JavaScript data.

| File | Mục đích | Được gọi từ |
|------|----------|-------------|
| `Dashboard.html` | Dashboard chính - chọn job, mode, template | `JobSelection.xaml` |
| `dashboard_data.js` | Dữ liệu jobs cho Dashboard | Generated by workflow |
| `Review.html` | Preview email trước khi gửi | `ReviewPhase.xaml` |
| `review_data.js` | Dữ liệu preview email | Generated by workflow |
| `EmailStatusReport.html` | Báo cáo delivery status | `Process_DeliveryStatusNotifications.xaml` |
| `email_status_data.js` | Dữ liệu email status | Generated by workflow |

**Đặc điểm:**
- Sử dụng **BR Omega font** cho tất cả UI
- Modern design với gradient, shadows
- Interactive: filter, search, real-time updates
- Communicate với UiPath qua `window.external.setResult()`

---

### 🔤 **Fonts/** - Font files
Chứa BR Omega font family.

```
Fonts/
├── BROmega-Regular-BF6556cee4dd400.otf    (400 weight)
├── BROmega-Medium-BF6556cee4bc2e2.otf     (500 weight)
└── BROmega-Bold-BF6556cee4cf0f3.otf       (700 weight)
```

**Sử dụng:**
- Dashboard HTML
- Email templates
- PDF generation
- Review UI

---

### 📥 **Input/** - Dữ liệu đầu vào
Chứa files input cho workflow.

| File | Mô tả | Format |
|------|-------|--------|
| `Jobs_Local.xlsx` | Danh sách jobs (copy từ Google Drive) | Excel |
| `Emails_Local.xlsx` | Danh sách emails (copy từ Google Drive) | Excel |
| `Job_Description.pdf` | PDF attachment được tạo | PDF |

**Lưu ý:**
- `Job_Description.pdf` được tạo bởi `GeneratePDF.xaml`
- Tạo **1 lần duy nhất** cho mỗi batch
- Tất cả emails trong batch dùng chung PDF này

---

### 📤 **Output/** - Kết quả
Chứa execution reports và logs.

**Format file:**
```
ExecutionReport_YYYYMMDD_HHMM.xlsx
```

**Nội dung:**
- Recipient email
- Status (Success/Failed)
- Error message (nếu có)
- Timestamp

---

### 🗂️ **Temp/** - Files tạm
Chứa temporary files trong quá trình xử lý.

| File | Mục đích |
|------|----------|
| `temp_email.html` | HTML tạm để generate PDF |

**Lưu ý:**
- Files này được tạo và xóa tự động
- Không nên chỉnh sửa thủ công

---

### ⚙️ **Config.xlsx** - Cấu hình
File cấu hình chính cho toàn bộ workflow.

**Các settings quan trọng:**

| Key | Mô tả | Ví dụ |
|-----|-------|-------|
| `GmailConnectionId` | Gmail connection ID | `a03a0f0a-762f-44c5-9d07-4d280413f2ed` |
| `JobEmail_SubjectTemplate` | Subject template | `Job Opportunities - {date}` |
| `JobEmail_AttachmentPath` | PDF path | `Data\Input\Job_Description.pdf` |
| `GoogleDrive_JobsFileId` | Google Drive file ID cho Jobs | `1abc...` |
| `GoogleDrive_EmailsFileId` | Google Drive file ID cho Emails | `1def...` |

## 🔄 Luồng dữ liệu

### 1. Input Flow
```
Google Drive (Jobs.xlsx, Emails.xlsx)
    ↓ [Download]
Data/Input/ (Jobs_Local.xlsx, Emails_Local.xlsx)
    ↓ [Read]
Workflow processing
```

### 2. UI Data Flow
```
Workflow
    ↓ [Generate JS]
Data/UI/*.js (dashboard_data.js, review_data.js, email_status_data.js)
    ↓ [Load]
Data/UI/*.html (Dashboard, Review, EmailStatusReport)
    ↓ [Display]
Browser
```

### 3. PDF Generation Flow
```
Template HTML (Templates/Group/*.html)
    ↓ [Merge data]
Data/Temp/temp_email.html
    ↓ [Edge headless]
Data/Input/Job_Description.pdf
    ↓ [Attach]
Email sent
```

### 4. Output Flow
```
Execution results
    ↓ [Write]
Data/Output/ExecutionReport_*.xlsx
```

## 📝 Lưu ý bảo trì

### ✅ Nên làm:
- Backup `Config.xlsx` trước khi thay đổi
- Kiểm tra font files tồn tại trước khi chạy
- Xóa files cũ trong `Output/` định kỳ
- Verify Gmail connection ID còn hoạt động

### ❌ Không nên:
- Xóa files trong `Fonts/` - sẽ làm lỗi PDF
- Chỉnh sửa `*.js` files thủ công - được generate tự động
- Đổi tên `Config.xlsx` - workflow sẽ không tìm thấy
- Di chuyển `Input/` folder - paths được hardcode

## 🔧 Troubleshooting

### PDF không tạo được?
- Kiểm tra font files trong `Fonts/`
- Verify Edge browser installed
- Check permissions trên `Input/` folder

### Dashboard không hiển thị?
- Kiểm tra `*.js` files được tạo
- Verify font paths trong HTML
- Check browser console for errors

### Email không gửi được?
- Verify `GmailConnectionId` trong Config
- Check `Job_Description.pdf` exists
- Review Gmail API permissions
