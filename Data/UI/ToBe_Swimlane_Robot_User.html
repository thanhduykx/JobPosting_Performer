TO-BE Swimlane: User and Robot

Approval-first flow: send to leader first, then mass send only when approved.

User
1. Provide Inputs
Select vacancies, template, and target recipients.
2. Preview and Confirm
Click confirm to trigger leader approval gate.
3. Leader Replies
Reply by email with APPROVE TOKEN or DENY TOKEN.
4. Track Final Result
View report after mass send is completed or blocked.
Robot
A. Read Config and Data
Read Canva sheet and GMail sheet, build dictionary.
B. Generate Posters
Create and export posters from Canva templates.
C. Send Approval Email
Send to leader with poster attachment and recipient list.
D. Wait Approval Decision
Poll inbox for APPROVE or DENY command.
E. Send Bulk Emails
Show “Sending Bulk Emails” page and send to all recipients.
F. Write Final Report
Summarize sent/failed results per poster and recipient.
Decision Rule: If leader replies DENY or no reply before timeout, robot blocks mass send and logs reason.
